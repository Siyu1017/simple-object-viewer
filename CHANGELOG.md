# Changelog

## [Unreleased]

### Fixed

## [1.0.0] - 2026-02-12

### Added

- Object rendering in expandable tree view
- Support for deeply nested structures
- Circular reference detection and safe rendering
- Display of `[[Prototype]]` chains
- Getter and setter detection without invocation
- Support for `Symbol` properties
- Function signature display
- Value type differentiation (String, Number, Array, Object, etc.)
- ESM and UMD builds
